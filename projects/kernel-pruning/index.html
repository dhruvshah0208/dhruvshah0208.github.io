Abstract

Subspace pruning finds a nearly Koopman-invariant subspace inside a large dictionary by repeatedly removing the principal vector that is worst aligned with the subspace's Koopman image. Kernel dictionaries are a natural fit for this, but the principal angles must then be computed in the inner product of a reproducing kernel Hilbert space (RKHS), where the Koopman image of a kernel section need not lie in the space and the kernel trick does not directly apply. Under an idealized dataset-invariance assumption, we express the Koopman image in kernel coordinates, obtain every required Gram matrix from kernel evaluations, and compute exact RKHS principal angles and vectors through an implicit QR factorization. This yields Kernel-SPV, whose cost is dominated by an O(N3) linear solve in the number of data points. To scale to large datasets, we replace the kernel with Nyström features on D ≪ N landmarks, which gives Approximate Kernel-SPV at cost O(NDs + D3), linear in the dataset size. On the undamped Duffing oscillator, D = 2000 features already reproduce the exact pruning sequence, and pruning from 200 kernel sections to 5 sharply reduces the eigenfunction prediction error relative to kernel EDMD.

Walkthrough

  • Open with one or two sentences pointing to the subspace pruning page for background on invariance proximity, principal angles and SPV pruning, so this page can start directly in the RKHS setting.

1RKHS basics and kernel EDMD

  • A symmetric positive-definite kernel k defines the RKHS 𝒩(X). Kernel sections Φx = k(·, x) have the reproducing property f(x) = ⟨f, Φx⟩, which gives the kernel trick ⟨Φxi, Φyj⟩ = k(xi, yj).
  • Notation: data matrices X and Y, ΦX, and KX,Y = ΦX⊤ΦY.

2Problem formulation

  • Problem 1: invariant subspace search in RKHS. Find the largest S* ⊆ S with invariance proximity δ(S*) ≤ ε, measured in the RKHS inner product. SPV solves it if we can compute Problem 2.
  • Problem 2: compute the principal angles and vectors between S and 𝒦S in ⟨·, ·⟩𝒩. In the Euclidean case this is a single SVD.
  • Contributions, in order: an exact RKHS routine (Gram matrices + SVD, O(N3)), a Nyström approximation (D ≪ N landmarks, O(NDs + D3)), and Kernel-SPV with its approximate version.

3The obstacle and a key assumption

  • Principal angles need four blocks of inner products. Three follow from the kernel trick, but (𝒦V)⊤(𝒦V) does not, because 𝒦Φy need not lie in the RKHS.
  • Assumption (idealized dataset invariance): span(𝒦V) ⊆ span(ΦX), so 𝒦V = ΦXW𝒦V. It is justified by RKHS universality.
  • Consequence: every block becomes a kernel-matrix product.

4Koopman image and Gram matrices

  • Lemma: the coefficients of the Koopman image solve KX,XW𝒦V = KT(X),XWV.
  • With them, MV, M𝒦V and Mcross are all computable, though possibly rank-deficient.
  • Bottleneck: the N × N solve costs O(N3). Add λI to KX,X for stability.

5Implicit QR via spectral truncation

  • The basis functions are known only through kernel sections, so they cannot be QR-factored directly, but their Gram matrix is enough.
  • Four steps: a truncated eigendecomposition of M (keep λ > τ), the square-root factor B, an economic QR of B, and a closed-form pseudo-inverse R†. The result is QV = VRV†, orthonormal in the RKHS inner product.
  • Numerics: Gram spectra decay fast, so a hard tolerance (for example τ = 10−8) avoids amplifying noise.

6Exact principal angles and vectors in RKHS

  • Theorem: the SVD of the cosine matrix M = (RV†)⊤McrossR𝒦V† gives cos θi = σi and the coefficients of the principal vectors.
  • Present Algorithm 1 as a short numbered list, or embed it as a figure. The cost is dominated by step 2, O(N3), which motivates the Nyström approximation.

7The Nyström approximation

  • Geometric view: project each kernel section onto the span of D landmark sections. The projected inner product gives k̃(x, y) = kL(x)⊤KL,L†kL(y).
  • Result: KX,X ≈ KX,LKL,L†KL,X, a lower bound on the true kernel that is exact on the landmarks.
  • The 3D projection diagram is worth keeping. Consider merging this section with the next one.

8Scaling up with explicit features

  • Sample D ≪ N landmarks (uniformly or by clustering) and form the explicit feature map ψ(x) = ΛL−1/2UL⊤kL(x) ∈ ℝD, so that KX,X ≈ Ψ(X)⊤Ψ(X).
  • Benefit: no N × N inversion, and no need to solve for the Koopman-image coefficients. Convergence improves as D grows, and it is most effective when the kernel spectrum decays quickly (Gittens & Mahoney, 2013).

9Target matrices and rank truncation

  • Goal: find D × s factors ZV and Z𝒦V whose Gram matrices approximate MV and M𝒦V.
  • The base subspace is direct (ZV = Ψ(X)WV). The Koopman image comes from Tikhonov-regularized least squares, which needs only a D × D inverse.
  • Rank mismatch: the true Gram matrices are rank-deficient, but the targets are generically full rank. Truncate singular values below τ(D) ∝ D−1/2 so that spurious directions do not corrupt the angles.

10Approximate principal angles and vectors

  • Regularized R factors come from the truncated SVDs. The bases are never formed explicitly, and the cosine matrix comes from known quantities.
  • Algorithm 2 mirrors Algorithm 1. Headline cost: O(NDs + D3) against O(N3), which is linear in the dataset size when s ≤ D ≪ N.
