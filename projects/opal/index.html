Learning Omega-Limit Partitions
from Approximate Koopman Invariants

Dhruv Shah, Jorge Cortés
UC San Diego · American Control Conference (ACC), 2027 (submitted)

Abstract

Continuous immersions into finite-dimensional linear systems cannot separate distinct omega-limit sets, so a single global Koopman model of a multistable system blurs its basin boundaries and drifts over long horizons. We instead partition the state space by long-term behavior and learn one Koopman model per region. The target is the omega-limit partition, which groups initial conditions by the set their trajectories converge to; it is stationary and canonical. We show that partitions built from approximate Koopman invariants refine the omega-limit partition everywhere except on an exception set of small measure. Building on this result, we propose OPAL (Omega-limit Partitions from Approximate invariants, Learned from data), which computes approximate invariants from snapshot data with a generalized eigenvalue problem, clusters their level sets, merges the resulting fragments, and shrinks the cells away from their boundaries. On a damped Duffing oscillator and a bistable oscillator, OPAL classifies every retained validation point correctly, and regional EDMD models built on its partition reduce long-horizon error by about 15× and 26× relative to a single global EDMD model.

Walkthrough

1Multiple attractors break global models

  • Open with the obstruction: continuous immersions into finite-dimensional linear systems collapse distinct omega-limit sets (Liu, Ozay & Sontag, 2025).
  • The consequence in practice: one global model blurs basin boundaries, and long-horizon predictions drift (the blue curves).
  • End on the idea: partition the state space into forward-invariant regions and learn one Koopman model per region.
  • The teaser figures already show both systems, so this section can be mostly text.

2Omega-limit sets define a canonical partition

  • Set up the dynamics x+ = T(x) on a compact state space, and define a partition as disjoint nonempty cells covering X.
  • Define the omega-limit set ω(x) in words ("where the trajectory ends up") and the omega-limit partition: x ~ y iff ω(x) = ω(y), grouping initial conditions by their fate.
  • A stationary partition has T(Cα) ⊆ Cα: trajectories never leave their cell.
  • Key claim: the omega-limit partition is stationary and canonical, the coarsest partition whose cells each share one omega-limit set.
  • Use the Duffing basin figure (C1, C2 basins; C3 the measure-zero stable manifold of the saddle).

3Goal: learn the omega-limit partition

  • Problem statement: given snapshot pairs (xi, yi = T(xi)) and a dictionary Ψ spanning S, find a partition close to Pω.
  • The tool: invariant observables, 𝒦f = f ⇔ f ∘ T = f. From data we only get approximate invariants.
  • Spell out the acronym: Omega-limit Partitions from Approximate invariants, Learned from data.
  • Preview the three-step story (theory → OPAL → regional models). This could be a small inline diagram instead of the slide.

4Approximate invariants refine the partition

  • This is the main theoretical result, so give it the most space.
  • Define the ε-approximate invariants Eεinv(S) = {f ∈ S : ‖𝒦f − f‖ ≤ ε‖𝒦f‖} and the induced partition Pε (points agree on every approximate invariant).
  • State the theorem informally: if the dictionary approximates the indicator of each positive-measure omega-limit cell well enough, then Pε refines Pω outside an exception set Bη whose measure is bounded by (1/η2) ∑ δi2.
  • Practical reading: the dictionary must approximate the indicators of the omega-limit cells.
  • Explain the cartoon: refining gives fragments, so the algorithm has to merge them back.

5OPAL: from data to a partition

  • Walk through the four steps, one short paragraph each:
    1. Approximate invariants: solve the generalized eigenvalue problem MΨc = λNΨc and keep eigenvectors with λ ≤ ε2.
    2. Cluster: split each scalar invariant into intervals. The label vectors that occur in the data give the fine cells.
    3. Merge: join cells using observed transitions and centroid distances, and drop cells with low occupancy.
    4. Shrink: trim each cell by a robustness margin τrobust away from its boundary.
  • Point readers to the OPAL-Koopman repo for the implementation.

6OPAL recovers both partitions

  • Give the two test systems with their equations:
    • Damped Duffing: ẋ1 = x2, ẋ2 = −0.5x2 + x1 − x13 (two stable equilibria, saddle at the origin).
    • Bistable oscillations: ṓ = (r − 2) − (r − 2)3, θ̇ = 1 (stable limit cycles at radius 1 and 3).
  • Partitions are already shown in the teaser, so swap this slide for the two rollout-error plots (regional vs. vanilla EDMD) exported from the repo.
  • Note the gray points: a thin unassigned band along the separatrix.

7Regional models: an order of magnitude better

  • Replace the slide with an HTML table: System / Model / Accuracy (dropped) / Step 50 / Step 300 (mean relative state error, units of 0.001). Duffing: regional 100% (0.42%), 22.6, 16.4; vanilla 100.0, 255.0; regional without margin 99.86% (0%), diverged (24 of 50). Bistable: regional 100% (0.23%), 9.2, 4.5; vanilla 71.3, 118.0; regional without margin 99.90% (0%), 18.8, 6.1.
  • Headline: about 15× lower error for Duffing and 26× for bistable at step 300.
  • Make the robustness-margin point: nearly correct is not enough. Without the margin, 99.86% accuracy still lets Duffing rollouts diverge.
  • Explain why the global model fails: it has a large steady-state error because it tries to fit two asymptotic behaviors at once.

8Summary

  • Four bullet takeaways: obstruction → theory → OPAL → regional EDMD, each with its one-line lesson from the slide.
  • Close on the key sentence: multiple omega-limit sets obstruct a single continuous finite-dimensional Koopman model, but not a collection of them.
