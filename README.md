# dhruvshah0208.github.io

Personal academic homepage, served by GitHub Pages at https://dhruvshah0208.github.io.

Plain static HTML/CSS, no build step (`.nojekyll` disables Jekyll).

- `index.html`: the whole site
- `stylesheet.css`: styles (light and dark mode)
- `images/`: profile photo (`profile.jpg`) and publication/project thumbnails
- `files/`: CV and other PDFs

Preview locally with `python3 -m http.server` and open http://localhost:8000.

Design adapted from [Nicklas Hansen](https://nicklashansen.com).
